
** Matrix Engine


An engine for Paradise that maps the spec of Matrix to the modular main client.
This enables Paradise to be a Matrix client, and so much more.



**** Testing / Developing

Currently, the best way to develop for and test can seem rather clunky.
However, since the dev mode for CLJS doesn't do dead code elimination we
end up with some problematic entries in the created bundle file.
So instead, when developing for the engine it is FAR easier to simply
point a module in the client repo directory that you have locally (or should)
and then launch the client.

Changes in the engine repo will trigger a re-compilation, so the overall
experience from that point should be smooth. Just a bit of set-up to
get started.
